# 从句（一个句子作某成分）

## 名词性从句

### 主语从句

1. 一个句子作主语

2. **结构**：连接词 + 陈述句 + 主句

3. **方法**：同宾语从句（that 不省略，可用 whether）

4. **两种位置**：

   1. 句首（谓语动词前，第一个单词为连接词）
   2. **it 作形式主语** + 主语从句后置

5. #### 常见句型

   1. **It is done + 主语从句**（表达对一件事的强调）
   2. **It is + adj./n. + 主语从句**（表达对一件事的评价）

### 宾语从句

1. 一个句子作宾语

2. **结构**：主句 + 连接词 + 陈述句

3. 方法

   1. 陈述句变宾语从句

      1. 前加 **that**，that 不作成分

   2. 特殊疑问句变宾语从句

      1. 调整语序：主语提前，变为陈述语序

   3. #### 一般疑问句变宾语从句

      1. 调整语序：主语提前，变为陈述语序
      2. 前置连接词：**if / whether**

4. 三种位置

   1. **动宾**：及物动词 + 人 + 从句
   2. **介宾**：介词 + 从句
   3. **形容词 + 宾语从句**

5. 注意

   1. **非谓语动词 + 从句**（doing / to do）
   2. 多个宾语从句的使用
   3. 宾语从句后置，用 **it** 作形式宾语
      1. 宾语从句过长所以后置
      2. 结构：主谓宾(it)    + 宾语从句

------

### 表语从句

1. 一个句子作表语
2. **结构**：主句 + 连接词 + 陈述句
3. **方法**：同宾语从句（但 **that 不省略**）
4. **位置**：
   1. 系动词后（be 动词后）:系动词 + 表语从句
   2. 非谓语动词 + 表语从句

------

### 同位语从句

1. **功能**：解释说明名词
2. **结构**：n. + 连接词 + 陈述句
3. **方法**：同宾语从句（常用 **that**）
4. 位置：**常见抽象名词后**（后接同位语从句）：
  - idea, opinion, fact, evidence, question, doubt, reason, theory, belief, possibility, chance, hope, contention, guarantee

------

## 定语从句(需要重构)

### 定语从句

1. 作用： 修饰限定名词
2. 结构：先行词n + 关系词 + 陈述句
3. 形式
   1. 定语从句所修饰的名词一定在从句前， 然后 + 先行词
   2. 定语从句关系词 = 先行词 (做成分不可忽略)
4. 先行词的选择
   1. 事/物：使用which /that
   2. 人 ：who/that/whom（只做宾语）
   3. 人/物：whose（表人/物的所属关系，.....的）
   4. 时间：when
   5. 地点：where
   6. 原因：why
5. 注意：
   1. 定语从句关系词必做成份
      1. whom指人，做宾语
      2. when/why/where 与先行词匹配
   2. 关系词在定语从句中做宾语，可以省略
   3. 特殊关系词whereby = by which ：通过......的方式
6. 比较：
   1. 限制性定语从句
      1. 无逗号。先行词范围不明确
      2. 用来修饰限定先行词，不省略
      3. 翻译成".......的名词"
      4. 关系词可以用that
      5. 作宾语省略
      6. 指人作宾语用whom/who/that
   2. 非限定性定语从句
      1. 有逗号，先行词范围明确
      2. 用来补充说明先行词，可省略
      3. 翻译时候，正常语序
      4. 关系词不用that
      5. 作宾语不省略
      6. 指人作宾语，只用whom
7. 补充
   1. 名词 + 从句比较
      1. 同位语从句
         1. 用来解释说明，在抽象名词后使用
         2. 名词 + that 从句(that 不做成分)
         3. 关系词不省略
      2. 限定性定语从句
         1. 用来修饰限定的
         2. 在任意名词后使用
         3. 名词 + that 作成分
         4. 名词 + 省略关系词(作宾语)
   2. 特殊的非限定性定语从句
      1. 修饰整句话，关系词用which /as 
   3. 介词提前的定语从句
      1. 介宾在一起
      2. 只用介词 + whom/which

## 状语从句

### 基础说明

1. 含义:一个句子作状语，表达描述性信息，补充说明另一个句子
2. 写法：一个完整的陈述句前面，再加上一个从属连词
3. 状语从句的种类是由从属连词的含义决定的
4. 位置
   1. 主句前
   2. 主句中
   3. 主句后

### 时间状语从句

| 从属连词          | 含义         |
| :---------------- | :----------- |
| when / while / as | 当……时候     |
| before            | 在……之前     |
| after             | 在……之后     |
| since             | 自从         |
| until             | 直到……       |
| as soon as        | 一……就……     |
| by the time       | 截止到……时候 |

### 地点状语从句

| 从属连词 | 含义     |
| :------- | :------- |
| where    | 在……地方 |

### 原因状语从句

| 从属连词 | 含义   |
| :------- | :----- |
| because  | 因为…… |
| since    | 因为…… |
| as       | 因为…… |

### 结果状语从句

| 从属连词       | 含义                                  |
| :------------- | :------------------------------------ |
| so...that...   | 太……所以……（so 后接形容词或副词）     |
| such...that... | 太……所以……（such 后接名词或名词词组） |
| so that...     | 所以……                                |

### 目的状语从句

| 从属连词         | 含义             |
| :--------------- | :--------------- |
| so that...       | 目的是（为了）…… |
| in order that... | 目的是（为了）…… |

### 条件状语从句

| 从属连词   | 含义   |
| :--------- | :----- |
| if         | 如果…… |
| once       | 一旦…… |
| as long as | 只要…… |
| so long as | 只要…… |

### 让步状语从句

| 从属连词              | 含义       |
| :-------------------- | :--------- |
| although / though     | 尽管、虽然 |
| even if / even though | 即使，虽然 |
| while                 | 虽然，尽管 |
| however               | 不管怎样   |

### 比较状语从句

| 从属连词 | 含义                         |
| :------- | :--------------------------- |
| than     | 和……相比较（用在比较级中）   |
| as       | 和……相比较（用在原级比较中） |

### 方式状语从句

| 从属连词 | 含义             |
| :------- | :--------------- |
| as       | 按照……方式，如同 |
| as if    | 似乎，好像       |

### 一词多义的as作从属连词，引导状语从句

1. 时间状语从句：“当……的时候”
2. 原因状语从句：“因为”
3. 比较状语从句：“和……相比较”
4. 方式状语从句：“按照……方式，如同”

## 特殊句式

### 虚拟语气

#### 基本概念

- **含义**：虚拟，就是非真实
  - 一是跟真实情况进行比较，发现与真实情况不符
  - 二是与假设的情况进行比较，发现即使假设，这件事也不太可能成真

#### 2.2 if 条件状语从句

1. | 类型       | 特点                             |
   | :--------- | :------------------------------- |
   | 真实条件句 | 假设事件是真的或可能是真的       |
   | 虚拟条件句 | 假设事件不是真的或不太可能是真的 |

2. **口诀**：从句往前推，主句四加一，将来同现在

#### 2.3 名词性从句的虚拟

- **适用条件**：只要主句中有表示“建议、命令、要求”的词，名词性从句都需要虚拟
- **格式**：把谓语动词变成 **“should + 动词原形”**，should 可以省略

### 倒装句

#### 全部倒装

- **There be 句型的基本结构**：There be + 名词，表示“有……”
- **There be 句型的扩展结构**：There be + 名词 + 介词短语，表示“有……在哪里”

#### 部分倒装（主谓倒装）

- **含义**：把谓语动词的一部分置于主语前
- **常见触发条件**：
  1. 否定副词或词组位于句首
  2. only 位于句首
  3. 虚拟条件句省略 if

### 强调句

- **含义**：通过强调传递重点信息
- **构成**：将想强调的部分放到 **“It is...that”** 中间，余下的部分放到 that 后
- **注意**：不可强调形容词和动词
