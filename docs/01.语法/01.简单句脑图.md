## 简单句构成

1. **主谓** = 主语 + 不及物动词（vi :主语能独立完成动作）
2. **主谓宾** = 主语 + 及物动词（vt: 主语无法独立完成）+ 宾语
3. **主谓双宾** = 主语 + 及物动词(vt) + 两个宾语（人 + 物）
   1. to 表示方向，for表示目的
   2. give sth to sb
   3. buy sth for sb

4. **主谓宾补** = 主语 + 及物动词(vt) + 宾语 + 宾语补足语
   1. 可以带宾补的动词
      1. 感官动词：hear/see/watch/feel/find ....
      2. 使役动词：let/make/have/get.....
      3. 要求类动词：wish/want/order/ask........

   2. 补语的形式
      1. 名词/代词：we elected him president
      2. 形容词：I found the problem difficult
      3. 非谓语动词： I saw him running in the park
      4. 介词短语：we consider the plan a waste of time
      5. 从句： I make it a rule that I go to bed before 11 o'clock
      6. 不定式to do( 使役动词 和感官动词 后的to 可被省略)

5. **主系表** = 主语 + 系动词（前后联系，无实义）+ 表语
   1. be 动词， 单独使用
   2. 变得：get、become、turn、go、grow
   3. 感官动词：look、sound、smell、taste、feel
   4. see、appear/keep、remain/prove


## 三态+否定+强调

------

### 时态

#### 一般时态

1. **一般过去时**：
   1. 谓语动词 = did（动词过去式）或 be → was/were
   2. 表示完全发生在过去的事，现在不这样了

2. **一般现在时**：
   1. 谓语动词 = do/does（动词原形或第三人称单数）
   2. 第三人称单数情况：
      1. 第三人称主语：he/she/it
      2. 不可数名词
      3. 可数名词单数

   3. 表示现在的状态/现在经常性、习惯性动作/表示永恒：科学事实、客观真理、名言警句

3. **一般将来时**：
   1. 谓语动词
      1. will + do (强调临时决定、有意愿)
      2.  am/is/are going to + do（强调实现有打算、有预兆）
      3. 第一人称之后，也可以+shell  (表示将来)

   2. 表示现在的将来，将来可能会发生但是不必然发生的事

4. **过去将来时**：
   1. 谓语动词 = would + do 或 was/were going to + do（过去的将来）
   2. 表示事情发生在过去的将来，要先有过去，所以通常与上下文的一般过去式搭配


#### 进行时态

1. **过去进行时**：谓语动词 = was/were + doing
2. **现在进行时**：谓语动词 = am/is/are + doing
3. **将来进行时**：谓语动词 = will be + doing（be 动词永远为 be）
4. **过去将来进行时**：谓语动词 = would be + doing（be 动词永远为 be）

#### 完成时态

- **核心概念**：① 全部完成 / 部分完成；② 站在某个时间点往前看事情的完成度

1. **过去完成时**：谓语动词 = had + done（过去的之前）
   1. 过去之前，搭配一般过去时使用
      1. 过去完成时先发生，一般过去式后发生

2. **现在完成时**：
   1. 谓语动词 = have/has + done
      1. 在hava/has 和done之间，可以加一些副词，如：already(已经)、just(刚刚)、ever(曾经)、never(从不)

   2. （现在的之前，过去的影响持续到现在，截止到现在，完成结果如何，可以全部完成，也可以完成一半）
      1. 全部完成：可与一般过去时互换使用
         1. 现在完成时强调影响
         2. 一般过去时，强调过去的时间

      2. 部分完成：与一般过去式不可互换

3. **将来完成时**：谓语动词 = will have + done

#### 完成进行时态

1. **过去完成进行时**：谓语动词 = had been + doing
2. **现在完成进行时**：谓语动词 = have/has been + doing
3. **将来完成进行时**：谓语动词 = will have been + doing
4. 助记
   1. 完成进行时，强调过程
   2. 完成时态，强调结果

### 语态（主动 / 被动）

#### 主动(除了被动都是)

#### 被动

1. 构成
   1. 构成：**be + done**
   2. 步骤：
      1. done = 被动的动作(将动词变成过去分词)
      2. be = 被动的时间、单复数(am/is/are   was/were)
   3. 写出被动语态的步骤
      1. 确定被动的动作，变为过去分词
      2. 确定被动的时间，把be变成对应的状态
      3. 根据主语，确定be动词的单复数
      4. 如果强调被动的动作发出者，可以在被动后加上“ by + 动作发出者 ”
2. 被动语态与时态结合
   1. 8种常用时态
      1. 一般过去时的被动： was/were + done
      2. 一般现在时的被动：am/is/are + being done
      3. 一般将来时的被动：will be + done
      4. 过去将来时的被动：would be + done
      5. 过去进行时的被动：was/were being + done
      6. 过去完成时的被动：had been done
      7. 现在进行时的被动：am/is/are + being done
      8. 现在完成时的被动：have/has + been done

   2. 主动、被动的句子中，表示时态的用词不同
      1. 主动语态的句子中：把谓语动词变为各种时态
      2. 被动语态的句子中：把be变成对应的各种时态

3. 被动语态与情态动词结合
   - 情态动词 + be + done（如 must be done、can be done）


### 情态动词

#### 基本情态动词

- can、will、shall、may、must
- could、would、should、might、(must 无过去式)（过去式或委婉形式）
  1. 表示相应的过去
  2. 表示现在的更委婉和客气的语气
  3. 用于虚拟语气


#### 使用特点

1. 情态动词 + 动词原形： 若谓语是be，就用情态动词 + be
2. 只有现在和过去两种时态
3. 没人人称的变化：即情态动词没有第三人称单数，永远用原形
4. 变否定/疑问：
   1. 变否定：直接在情态动词后加not
   2. 变疑问：直接把情态动词提到主语前

#### 情态动词的用法

1. 表情态
   - **must** – 必须
   - **can/could** – 能够、可以
   - **will/would** – 愿意、将要
   - **may/might** – 可以、可能
   - **should** – 应该
2. 表推测（可能性程度）
   1. 可能性最大：**must**
   2. 中间程度：其余情态动词
   3. 可能性最小：**can**
3. 常用结构及变体结构
   1. 最常用形式：**情态动词 + have done**（表示对之前的推测）
   2. be doing (正进行时态推测情态)

### 谓语动词的否定

1. **实义动词变否定**：助动词 do/does/did + not + 动词原形
2. **助动词和情态动词变否定**：
   - 助动词 / 情态动词 + not（适用于 be 动词、情态动词、完成时态中的 have 等）

### 谓语动词的强调

- 使用助动词：**do/does/did + 动词原形**

## 主语、宾语、表语的变化

#### 名词、代词作主语、宾语、表语

#### 非谓语动词 doing 作主语、宾语

- **doing 作主语**：谓语动词用单数形式
  - （doing / done 单独出现时为非谓语）
  - 不一定只有一个词、可能是一个词组
  - 其他修饰限定的成分：形容词、副词、介词短语
- **doing 作宾语**
  - 动宾(位于及物动词后)
  - 介宾（位于介词后）

- **doing作表语**
  - 不常见，易于进行时混淆


#### 非谓语动词 to do 作主语、宾语、表语

- （to do 单独出现时为非谓语）
- **to do 作主语**：常后置，用 it 作形式主语
  - to do 作主语，谓语动词用单数，多个并列用复数
  - 不一定只有一个词，可能是数组
  - to do 或to do 词组放句首情况较少，绝大数用于句尾，举手用形式主语it替代

- **to do 作宾语**：很少后置
  - 只能位于及物动词后作动宾
  - 真正的宾语较长，且位于主谓宾补结构中时，to do 作宾语可以后置，形式宾语用it

- **to do 作表语**：很少出现
  - 位于系动词后，通常是be动词后


#### 表语的变化

1. 形容词做表语
   1. you are beautiful
2. 名词
   1. I am a woman
3. 介词短语
   1. she is at home
4. 副词
   1. The TV is on
5. 动名词/不定式
   1. My hobby is skating
   2. Their plan is to run away
