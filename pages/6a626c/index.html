并列句

# 并列句

# 构成(多个简单句 + 并列连词)

# 并列连词分类

# 顺接关系

  • and ……和……
  • both...and... 两者都……
  • not only...but...as well 不但……而且……
  • not only...but also... ……和……（不但……而且……）
  • not only ...... but

# 转折关系(出乎意料的结果)

  • yet ……
  • ...while... ……
  • ...whereas... ……
  • ...but... ……

# 选择关系

  • ...or... ……或者……
  • either...or... （二者之一）
  • neither...nor... 既不……也不……（两个都不选）

# 因果关系

  • for ……因为……
  • so ……所以……

# 说明

  1. 多件事都可以用并列连词在一起
  2. 多个并列连词一样的，用逗号表示

# 并列句的省略

  1. 哪里相同，省略哪里(只有并列句有)
  2. 相同的部分省略，余下的部分保持不变
  3. 关于有界、无界的充分条件
