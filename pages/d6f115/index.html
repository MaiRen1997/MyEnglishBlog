  1. 时态
    1. 16种时态
  2. 语态
    1. 主动语态
    2. 被动语态： be + done
    3. 被动语态与时态结合
      1. 一般过去时被动： was/were + done
      2. 一般现在时被动： am/is/are + done
      3. 一般将来时被动： will be done
      4. 过去将来时被动： would be done
      5. 过去进行时被动： was/were being done
      6. 现在进行时被动：am/is/are being done
      7. 过去完成时被动： had been done
      8. 现在完成时的被动： have/has been done
    4. 被动语态 + 情态动词：情态动词 + be done，be一定要用原型
  3. 情态
    1. 否定
