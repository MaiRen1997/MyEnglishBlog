雅思题型分析

# 听力

  • 考试时间：约30分钟听力+10分钟誊写答案。

  • 题目数量：共40道题。

  • 题型：题型多样，录音只播放一遍。

    • 填空题 (表格、笔记、流程图、摘要总结)

      • 两个人对话，内容：问机构，健身、煮饭、旅游、求职等，10个空

    • 第二、第三部分有以下几种类型：但是顺序不固定

      • 选择题 (单选、多选)

        • 比如一个人去探险旅行，出发前需要带什么，但是后面不带了，容易将不带的也选上

      • 匹配题 (将信息与选项配对)

        • 有几个描述对象，然后针对每个对象进行描述，里面有同义词替换，

      • 地图/图表标签题 (在地图或图表上标注信息)

        • 一个人问另外一个人，地点在哪里：第一个左拐是咖啡厅，左拐是银行，等等.......

    • 第四部分：依然是填空题

      • 但是是一个人的独白：大概率是科普文章

# 阅读

  • 考试时间：60分钟（总共3篇文章，每篇文章跟13~14道题目）总共40道题目。
  • 题目数量：共40道题。
  • 主要题型：
    • 判断题 (TRUE/FALSE/NOT GIVEN 或 YES/NO/NOT GIVEN)
    • 匹配题 (匹配标题、段落信息、人物观点、句尾等)
      • 每个段落，总结出来一个句子：如果难度提高，可能答案既能用到A段落，也能用到B段落
    • 选择题 (单选、多选)
      • 对于多选：比如科学家主张哪些观点，让你选出来
    • 填空题 (摘要、笔记、表格、流程图、句子填空)
    • 简答题
  • A类与G类区别：
    • A类：3篇较长的学术类文章。
    • G类：由较短的、生活实用类文章组成（如广告、说明书、公司政策）

# 写作

  • 考试时间：60分钟。（标题建议20分钟小作文 + 40分钟大作文）但是实际不限制，60分钟写完这两篇即可
  • 题目数量：2个写作任务（大作文与小作文）。
  • A类写作任务：
    • Task 1：描述图表信息（如折线图、饼图、表格、流程图、地图等），至少150字。
      • 如折线图、饼图：呈现一种现象，要归纳这种特征
      • 地图：一个是过去；一幅是现在，或者一个是现在；一个是将来。让分析出哪里发生了变化
      • 流程图：蜂蜜怎么制作，砖头怎么制作，主要的步骤和关键的单词都会给出，让我们把流程串起来
    • Task 2：就一个观点或问题写议论文，至少250字。
      • 比如找工作的时候，工资是不是重要因素，你同意还是不同意
  • G类写作任务：
    • Task 1：根据给定情境写一封信（如投诉信、咨询信、感谢信），至少150字。
    • Task 2：与A类Task 2类似，写一篇议论文，至少250字

# 口语

  • 考试时间：11-14分钟（与考官一对一面试）。
  • Part 1 (4-5分钟)：问答。考官会问一些关于你个人生活、家庭、工作、兴趣爱好等熟悉话题的问题。
    • 考官会问：你叫什么名字、你来自哪里，家乡怎么样
    • 你有收集东西的习惯吗？你收集了哪些东西?现在还保留这些东西吗？
  • Part 2 (3-4分钟)：个人陈述。考官给你一张话题卡，你有1分钟准备时间，然后就话题进行1-2分钟的发言。(如果没有2分钟，考官会让你继续说下去)
    • 卡上的主题：人、事、物、地点
    • 人：请你描述一个一起共事过、一起学习过、一起生活过的人
    • 事：请你描述一个目前位置你觉得最大的挑战的事
    • 物：请你描述一个别人送给你的礼物
    • 地点：请你描述一个你经常去，或者你喜欢的咖啡馆
  • Part 3 (4-5分钟)：双向讨论。考官会就Part 2的话题，与你进行更深层次的探讨和追问，话题会更抽象、更广泛
    • 这里会比较生活、比较抽象的探讨，比如前面谈论的是旅游景点：
      • 你认为老年人和青年人喜欢的旅游景点有哪些不同
      • 你认为旅游景点是否应该免费
