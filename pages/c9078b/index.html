As作关系代词

As 作关系代词的详细用法 As 作关系代词时，不能像 which/that 那样随便用。它只有两种固定的“骨架结构”，且语体非常正式。

结构 1：Such + 名词 + as ... （表示“像……那样的”） 底层逻辑：这里的 as 代替了前面的名词，在后面的定语从句中充当主语或宾语。整个结构意为“属于那一类的……”。

公式：Such (a/an) + 名词 + as + 从句（缺主语或宾语）

作主语（不可省略）：

例：We need such a man as knows the answer.

解析：主句是“我们需要一个人”，从句是 as knows the answer。这里的 as 指代 man，在从句中作 knows 的主语。意为“像那个知道答案的那类人”。

作宾语（可省略，但通常保留）：

例：I want to buy such a book as you recommended.

解析：从句是 as you recommended。as 指代 book，作 recommended 的宾语（你推荐了这本书）。意为“像你推荐的那类书”。

⚠️ 极度易错点（与 so...as 区分）：

such...as 引导的是定语从句（as 作成分）。例：This is such a heavy box as I can carry.（我能搬动的那种箱子）

such...that 引导的是结果状语从句（that 不作成分，只连接）。例：This is such a heavy box that I can't carry it.（箱子重到我搬不动。注意：that从句中主谓宾齐全，it 指代箱子）

区别诀窍：看从句里缺不缺主语或宾语。缺成分，用 as；不缺成分，用 that。

结构 2：The same + 名词 + as ... （表示“与……相同的”） 底层逻辑：强调同类事物（并非同一个）。

公式：The same + 名词 + as + 从句

例：I have the same pen as you lost.

解析：我有一支笔，它和你丢的那支笔是同款（同类，但不是你丢的那支）。as 指代 pen，作 lost 的宾语。

🔥 超级大坑（The same...as 与 The same...that 的本质区别）：

这是考试中区分“顶级高手”和“普通选手”的试金石。

结构 指代关系 中文翻译 例句对比 the same ... as 同类（相似的，不是同一个） “像……一样的” This is the same phone as I bought. （这部手机和我买的那个是同款，但不是同一个） the same ... that 同一个（就是它本身） “正是那个……” This is the same phone that I lost. （这正是我丢的那部手机，失而复得） 深层逻辑：as 表示“比较”和“类别”；that 表示“特指”和“唯一”。

结构 3：As 引导非限制性定语从句（指代整个主句） 这是 which 的“死对头”。As 和 Which 都可以指代前面一整件事，但位置截然不同。

As 的位置：可放在句首、句中、句末（非常灵活）。

Which 的位置：只能放在主句之后（不能放句首）。

例 1（放句首）：As we all know, he is a genius. （众所周知，他是个天才）

例 2（放句中）：He is, as we all know, a genius.

例 3（放句末）：He is a genius, as we all know. （= which we all know，但 which 不能放句首）

常见的固定搭配（学术写作高频）：

as is often the case（情况常常如此）

as is mentioned above（如上所述）

as we can see（正如我们看到的那样）
