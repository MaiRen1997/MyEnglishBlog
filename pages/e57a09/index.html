简单句扩展脑图

# 词性扩展

# 限定词修饰名词

  1. 限定词分类
    1. 冠词： the / a / an
    2. 数词
    3. 名词所有格
    4. 名词
    5. 注：限定词用来修饰名词，可以同时出现多个

# 形容词(一般限定名词)/副词(一般限定动词)

# 形容词、副词作修饰成分

# 形容词修饰名词
  • 限定修饰名词(放在名词前后作定语)
  • 放在系动词后面作表语（主 + 系动词 + 形容词）
# 副词
  • 修饰动词、句子、其他的形容词或副词

# 形容词 / 副词的三种比较级别

  1. 原级比较：(not) as + adj./adv. 原形 + as + 比较对象
    • 含义：（不）和……相比一样的……
  2. 比较级：adj./adv. 的比较级 + (than + 比较对象)
    • 范围：两者之间
    • 含义：比……更……
  3. 最高级：adj./adv. 的最高级 + (介词短语表示比较范围)
    • 范围：三者或更多
    • 含义：最……

# 介词短语

# 介词的说明

  1. 不可单独使用
  2. 介词后接名词、代词(用宾格)、动名词
  3.
    1.副词性用法 作状语(最常见)
    2.形容词性用法 作定语/表语/宾语补足语
    3.名词性用法 作主语/宾语/同位语(最少见)

# 介词的用法

  1. 后面要接词，不能单独使用
  2. 常接名词、代词（宾格）、动名词（doing）来构成介词短语
  3. 介词短语又叫介宾短语，后接的成分作宾语，是句子的非核心成分

# 表时间的介词

介词 用法
before / after 在……时间之前 / 之后
from / （since +过去：要搭配现在完成时） 自从……时间
at / on / in 在……时间点 / 在……时间上 / 在……时间内
（by+时间：绝大部分情况搭配完成时） / until 截止到（直到）……时间
for + 时间 持续……时间
during 在……期间

# 3.3 表地点的介词

介词 用法
at / in 在……地点 / 在……里面
on / above / over / under / below 在……上面 / 下面
in front of / behind 在……之前 / 之后
near / by 在旁边
between 在两者之间
among 在三者或以上之间
around 在……周围
into / out of 进入……里面 / 从……里面出去
onto / off 到……上面 / 脱离……
across / through / past 穿过…… / 经过……
along 沿着……
from / to 来自…… / 朝着……去

# 3.4 其他用法介词

介词 用法
of ……的（表示属性，A of B 翻译成 B 的 A， A of B of C: “C的B的A”）
about 关于……
with / without 伴随着有…… / 没有……
for 因为……（表原因）；
为了……（表目的）；
对于……（表对象）
by + 名词/doing： 通过……方法或方式；
被动语态 + by + 动作的发出者： 被……做（被动语态 + by + 动作发出者）；
相差了……（表示变化的差额）
as 作为……；
像……一样，如同……
like 像……一样
despite 尽管……
in spite of = despit
although/though 是连词，需要接句子

# 成分角度扩展

# 非谓语动词

# 核心规则

  • 一主一谓配对以后，多余动词即为非谓语动词
  • 三种基本形式：
    1. doing – 表主动
    2. done – 表被动
    3. to do – 表目的
  • （注：单独出现时才是非谓语动词）
  • 找到非谓语动词的完整词组
  • 看清楚修饰名词、还是修饰句子
  • 看非谓语动词是否核心（作主宾表语）决定去留

# 非谓语动词作定语

  • 修饰限定名词，翻译成 ” .....的 “
  • 逻辑主语为所修饰的名词

# 非谓语动词作状语

  • 修饰限定句子、逻辑主语为句子主语，通常翻译成独立的一句
  • 为了更加明确的表达补充的是什么内容，可以在非谓语动词前加上从属连词，突出表达和句子间的逻辑关系
  • 有时一句中常常出现多个非谓语动词，逐个看
  • 注：非谓语动词作状语时，一般有逗号隔开

# 同位语 & 插入语

# 同位语

  • 解释说明名词，表示同一件事情
  • 特点： 逗号、破折号、冒号

# 插入语(补充信息插入，补充说明句子)

  1. 特点：成对出现逗号或者破折号，但有时候没有标点隔开
  2. 常用形式
    1. 主谓结构作插入语，表示某人说，某人认为
    2. 副词作插入语
      1. however 不能接两句，可做插入语
      2. but可以作连词来连接两句话
    3. 介词短语作插入语
