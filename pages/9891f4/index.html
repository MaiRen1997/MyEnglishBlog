复合句

# 从句（一个句子作某成分）

# 名词性从句

# 主语从句(重要)

  1. 一个句子作主语

  2. 结构：连接词 + 陈述句 + 主句

  3. 方法：

    1. 同宾语从句

    2. that 不作成分，但也不可以省略

    3. 可用 whether，只能用weather，不能用if

  4. 两种位置：

    1. 句首：（谓语动词前，第一个单词为连接词）
    2. 句尾：it 作形式主语 + 主语从句后置

  5. # 常见句型

    1. It is done + 主语从句（表达对一件事的强调）
    2. It is + adj./n. + 主语从句（表达对一件事的评价）

# 宾语从句(重要)

  1. 一个句子作宾语

  2. 结构：主句 + 连接词 + 陈述句

  3. 写法方法

    1. 陈述句变宾语从句

      1. 前加 that，that 不作成分，可以省略，然后直接并入

    2. 特殊疑问句变宾语从句

      1. 调整语序：主语提前，变为陈述语序

    3. 一般疑问句变宾语从句

    4. 调整语序：主语提前 2. 前面加连接词：if / whether 3. 保留是否的含义

  4. 三种位置

    1. 动宾：及物动词 + 人 + 从句
      1. 动单宾：vt + 从句
      2. 动双宾：vt + 人 + 从句
    2. 介宾：介词 + 从句
    3. 形容词 + 宾语从句
    4. 非谓语动词 + 宾语从句(和谓语动词一样)
    5. 后置，it作形式宾语

  5. 注意

    1. 非谓语动词 + 从句（doing / to do）
    2. 多个宾语从句的使用
    3. 宾语从句后置，用 it 作形式宾语
      1. 宾语从句过长所以后置
      2. 结构：主谓宾(it) + 宾语从句

# 表语从句

  1. 一个句子作主语的表语
  2. 结构：主句 + 连接词 + 陈述句
  3. 方法：同宾语从句（但 that 不作成分时，也不能省略）
  4. 位置：
    1. 系动词后（be 动词后）:系动词 + 表语从句
    2. 非谓语动词 + 表语从句

# 同位语从句(重要)

  1. 功能：一个句子作主句的同位语，解释说明前面的抽象名词
  2. 结构：n. + 连接词 + 陈述句
  3. 方法：
    1. 同宾语从句
    2. 多是 that + 陈述句，连接词不可省略
  4. 位置：常见抽象名词后（后接同位语从句）：
  • idea, opinion, fact, evidence, question, doubt, reason, theory, belief, possibility, chance, hope, contention, guarantee

# 定语从句(需要重构)

# 定语从句

  1. 作用： 修饰限定名词
  2. 结构：先行词n + 关系词 + 陈述句
  3. 形式
    1. 定语从句所修饰的名词一定在从句前， 然后 + 先行词
    2. 定语从句关系词 = 先行词 (做成分不可忽略)
  4. 先行词的选择
    1. 事/物：使用which /that
    2. 人 ：who/that/whom（只做宾语）
    3. 人/物：whose（表人/物的所属关系，.....的）
    4. 时间：when
    5. 地点：where
    6. 原因：why
  5. 注意：
    1. 定语从句关系词必做成份
      1. whom指人，做宾语
      2. when/why/where 与先行词匹配
    2. 关系词在定语从句中做宾语，可以省略
    3. 特殊关系词whereby = by which ：通过......的方式

# 定语从句的分类

  1. 比较：

    1. 限制性定语从句 非限定性定语从句
      逗号 无逗号 有逗号
      先行词 范围不明确 先行词范围明确
      作用 用来修饰限定先行词，不省略，影响表意 用来补充说明先行词，可省略，不影响表意
      翻译 往前翻译，翻译成".......的名词" 翻译时候，正常语序，不用往前翻译
      关系词 关系词可以用that 关系词不用that
      关系词 作宾语省略 作宾语不省略
      关系词 指人作宾语用whom/who/that 指人作宾语，只用whom

    2. 限制性定语从句

      1. 无逗号。先行词范围不明确
      2. 用来修饰限定先行词，不省略
      3. 翻译成".......的名词"
      4. 关系词可以用that
      5. 作宾语省略
      6. 指人作宾语用whom/who/that

    3. 非限定性定语从句

      1. 有逗号，先行词范围明确
      2. 用来补充说明先行词，可省略
      3. 翻译时候，正常语序
      4. 关系词不用that
      5. 作宾语不省略
      6. 指人作宾语，只用whom

# 定语从句补充

  1. 同位语从句与限定性定语从句的区别
    1. 同位语从句
      1. 用来解释说明名词(what)，
      2. 在抽象名词后使用，(不抽象的名词，一定是定语从句)
      3. 名词 + that 从句(that 不做成分)
      4. 关系词不省略
    2. 限定性定语从句
      1. 用来修饰限定的名词(which)
      2. 在任意名词后使用
      3. 名词 + that 作成分
      4. 名词 + 省略关系词(作宾语)，关系词可省略
  2. 特殊的非限定性定语从句(修饰整句话)
    1. 修饰整句话，关系词只能用which /as，都要作成分
      1. which 引导的非限定性定语从句，只能位于主句后
      2. as 引导的非限定性定语从句，可以位于主句的前、中、后
  3. 介词提前的定语从句
    1. 介词提前，则关系词不能省略，不能用that
      1. furthermore,humans have the ability to modify the environment in which they live in（in 提前了）
    2. 介宾在一起
    3. 只用介词 + whom/which
      1. 指人，用介词 + whom
      2. 指物，用介词 + which
    4. 除了限定性定语从句，非限定性定语从句也可以介词提前

# 状语从句

# 基础说明

  1. 含义:一个句子作状语，表达描述性信息，补充说明另一个句子

  2. 写法：一个完整的陈述句前面，再加上一个从属连词

    1. 从属连词，不做成份
    2. 用来表达意思的，表达什么意思，就加相应的从属连词

  3. 状语从句的种类是由从属连词的含义决定的

  4. 位置

    1. 主句前
    2. 主句中(不建议使用)
    3. 主句后

# 时间状语从句

从属连词 含义
when / while / as 当……时候
before 在……之前
after 在……之后
since 自从
until 直到……
as soon as 一……就……
by the time 截止到……时候
each time / every time 每一次
the next time 下一次

# 地点状语从句

从属连词 含义
where 在……地方

# 原因状语从句

从属连词 含义
because 因为……
since 因为……
as 因为……
now that 既然，由于......

# 结果状语从句

从属连词 含义
so...that... 太……所以……（so 后接形容词或副词）
such...that... 太……所以……（such 后接名词或名词词组）
so that... 所以……

# 目的状语从句

从属连词 含义
so that... 目的是（为了）……
in order that... 目的是（为了）……

# 条件状语从句

从属连词 含义
if 如果……
once 一旦……
as long as 只要……
so long as 只要……

# 让步状语从句

从属连词 含义
although / though 尽管、虽然
even if / even though 即使，虽然
while 虽然，尽管
however/ no matter how 不管怎样

# 比较状语从句

从属连词 含义
than 和……相比较（用在比较级中）
as 和……相比较（用在原级比较中）

# 方式状语从句

从属连词 含义
as 按照……方式，如同
as if 似乎，好像

# 一词多义的as作从属连词，引导状语从句

  1. 时间状语从句：“当……的时候”
  2. 原因状语从句：“因为”
  3. 比较状语从句：“和……相比较”
  4. 方式状语从句：“按照……方式，如同”

# 特殊句式

# 虚拟语气

# 基本概念

  1. 什么是虚拟（虚拟，就是非真实）
    1. 与真实情况不符
    2. 与假设情况相比，成真的可能性很小，或没有
  2. 如何表达虚拟
    1. 谓语动词改变时态
  3. 虚拟用在哪里
    1. if 虚拟条件句
    2. 名词性从句的虚拟

# 2.2 if 条件状语从句

  1. 类型 特点
    真实条件句 假设事件是真的或可能是真的
    虚拟条件句 假设事件不是真的或不太可能是真的

  2. 口诀：从句往前推，主句四加一，将来同现在

    1. 假设现在

      1. 从句往前推一个时态did(be动词只能用were)
      2. 主句 could/would/should/might + do

    2. 假设过去

      1. 从句往前推一个时态had done
      2. 主句 could /would/should /might + have done

    3. 假设将来(少)

      1. 从句

        1. did (were)
        2. were to do
        3. should do

      2. 主句

        1. could /would / should /might + do

# 2.3 名词性从句的虚拟

  • 适用条件：只要主句中有表示“建议、命令、要求”的词（无论词性如何），名词性从句都需要虚拟
  • 格式：把谓语动词变成 “should + 动词原形”，should 可以省略

# 倒装句

# 全部倒装(谓语动词全部置于主语前)

  • There be 句型的基本结构：There be + 名词，表示“有……”
  • There be 句型的扩展结构：There be + 名词 + 介词短语，表示“有……在哪里”

# 部分倒装（主谓倒装）

  • 含义：把谓语动词的一部分置于主语前，表强调

    • 相当于陈述句变一般疑问句

  • 常见触发条件：

    1. 否定副词或词组位于句首
    2. only 位于句首
    3. 虚拟条件句省略 if

# 强调句

  1. 含义：通过强调传递重点信息

  2. 构成：将想强调的部分放到 “It is...that” 中间，余下的部分放到 that 后

    • it is（强调的部分） that ........

    • 除了形容词/动词外，都可以强调；可以是词、词组，也可以是从句

  3. 强调句的变化

    1. 时态
      1. 现在的事：is
      2. 过去的事：was
    2. 强调人，可以把that换成who

  4. 注意：不可强调形容词和动词

  5. 补充：与主语从句(后置)的区分

    1. 去掉 it is ....... that
      1. 余下部分可以还原成完整的句子：强调句
      2. 余下的部分，不能还原成完整的句子：主语从句
